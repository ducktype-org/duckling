Duckling source docs
====================

This documentation offers comprehensive resources 
**for developers** contributing to Duckling.

The documentation is divided into the following sections:

* :doc:`source-doc/dev-guides/index` - guidelines, tutorials, and instructions 
  for writing and documenting code.
* :doc:`source-doc/dev-handbook/index` - a high-level overview of the source code.

If you are new to the project, we recommend starting with the
:doc:`source-doc/dev-guides/build-guidelines/index` guide.

.. note:: 
   If you are looking for information on how to use Duckling programming language, 
   please refer to the :ref:`duckling-doc`.

.. seealso::
   If you are looking for something specific, you can use the search functionality :ref:`search`.
