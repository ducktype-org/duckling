==============
Unique pointer
==============

.. simple-description::

Unique pointer is an extension of :code:`std::unique_ptr`.
Its provides the same functionalities as well as borrow methods:

* :code:`.borow()` -- creates immutable borrow pointer.
* :code:`.borow_mut()` -- creates mutable borrow pointer.

See :doc:`borrow_pointer` for more info.
