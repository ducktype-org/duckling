### quackpack.core.storage

Filesystem layout, paths, locks, and high-level storage orchestration.

## `storage.py`
Orchestrates operations that touch storage; integrates with runners.

## `files.py`
File abstractions (e.g., venv freeze), and utilities.

## `paths.py`
Helpers for deriving cache/config/data locations.

## `locks.py`
Storage-level locking.

## `git_access.py`
Helpers for reading from git-backed sources.
